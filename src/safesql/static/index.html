How it works

  

    
1 · Static guard
Parses with sqlglot and decides on the tree: one statement, SELECT only, no write or lock node anywhere, every function and table on an allowlist.

    
2 · Rewrite
Injects a row limit and runs SQL regenerated from the checked tree, comments stripped and re-parsed. Text the guard never saw can't run.

    
3 · Runtime limits
Read-only transaction, statement timeout, an EXPLAIN cost cap before execution, and prepared statements that refuse stacked queries.

    
4 · Database role
A role with SELECT grants only, read-only by default, dangerous functions revoked. It holds even if every layer above failed.
